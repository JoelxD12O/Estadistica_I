# Banco de Exámenes y Material Académico — UTEC
Repositorio creado con el objetivo de apoyar a la comunidad universitaria mediante la recopilación de ejercicios, quizzes, parciales, avances y material académico utilizados durante el ciclo.

## Objetivo
Brindar una referencia de estudio para estudiantes que deseen reforzar conocimientos y prepararse para evaluaciones académicas.

## Contenido
- Quizzes
- Parciales
- Avances de proyectos
- Ejercicios y ejemplos
- Material complementario
- Resúmenes y PDFs
  
## Aviso
Este repositorio tiene únicamente fines educativos y de apoyo académico.  
Se recomienda utilizar el material como guía de estudio y complementar el aprendizaje con práctica propia.

## Contribuciones
Cualquier aporte, corrección o mejora es bienvenido.
